# 评测基准说明：社区版 vs 商业版

本目录用于公开说明 **青椒智能脱敏 · 开源社区版** 与 **青椒智能脱敏 · 商业专业版（Desktop / Pro）** 的识别能力差距与评测口径，避免夸大宣传，也帮助开发者与企业团队判断是否需要升级商业版。

## 1. 社区版实测指标（阿里 ModelScope 开源 RaNER，纯模型）

- 模型：`iic/nlp_raner_named-entity-recognition_chinese-base-news`（MSRA 语料训练，约 400 MB PyTorch 权重）
- 配置：**纯 NER 模型，不搭配商业规则引擎**
- 支持实体：**3 类**（人名 `PERSON`、机构 `ORGANIZATION`、地名 `LOCATION`）

### 公开第三方数据集：CLUENER2020 dev（1,343 句新闻）

| 实体类型 | 金标数 | 精确率 (Precision) | 精确召回 (Recall) | 精确 F1 | 覆盖召回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 人名 (`PERSON`) | 465 | 0.715 | 0.884 | **0.790** | 0.893 |
| 机构 (`ORGANIZATION`) | 992 | 0.738 | 0.690 | **0.713** | 0.730 |

> 说明：在真实新闻和业务文本上，通用开源 RaNER 对机构的覆盖召回约为 73%（约 27% 机构可能漏检或截断），且无法识别手机号、身份证号、银行卡、统一社会信用代码、案号、金额、证券代码、律师执业证、政策文件、法律法规、职位、称谓、项目名称及文件名称。**对外发送前请务必在工作台内人工复核。**

### 复现命令

curl -L -o /tmp/cluener.zip https://storage.googleapis.com/cluebenchmark/tasks/cluener_public.zip
unzip -o /tmp/cluener.zip -d /tmp/cluener
