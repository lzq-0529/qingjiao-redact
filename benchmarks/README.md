# 评测基准说明：社区版 vs 商业版

本目录用于公开说明 **青椒智能脱敏 · 开源社区版** 与 **青椒智能脱敏 · 商业专业版（Desktop / Pro）** 的识别能力差距与评测口径，避免夸大宣传，也帮助开发者与企业团队判断是否需要升级商业版。

## 1. 社区版实测指标（阿里 ModelScope 开源 RaNER + 基础正则）

- 模型：`iic/nlp_raner_named-entity-recognition_chinese-base-news`（MSRA 语料训练，约 400 MB 权重）
- 基础正则：标准格式与校验位规则（`电话`、`邮箱`、`身份证号`、`银行卡号`、`IPv4`）
- 支持实体：**8 类**（`PERSON`、`ORGANIZATION`、`LOCATION` + 5 类基础正则字段）

### 公开第三方数据集：CLUENER2020 dev（1,343 句新闻）

| 实体类型 | 金标数 | 精确率 (Precision) | 精确召回 (Recall) | 精确 F1 | 覆盖召回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 人名 (`PERSON`) | 465 | 0.72 | 0.88 | **0.79** | 0.89 |
| 机构 (`ORGANIZATION`) | 992 | 0.74 | 0.69 | **0.71** | 0.73 |

> 说明：在真实新闻和业务文本上，通用开源 RaNER 对机构的覆盖召回约为 73%（约 27% 机构可能漏检或截断），且无法识别手机号、身份证号、银行卡、统一社会信用代码、案号、金额、证券代码、律师执业证、政策文件、法律法规、职位、称谓、项目名称及文件名称。**对外发送前请务必在工作台内人工复核。**

### 速度与资源对比（纯 CPU，无需 GPU）

| 指标 | 开源社区版（RaNER） | 商业版（青椒自研高精度引擎） |
| --- | --- | --- |
| 本地依赖体积 | ~400 MB（开源模型权重） | **极轻量本地推理包（无需 GPU）** |
| CPU 推理速度 | 长文 ~55.3 s（~0.8 s/块） | **0.45 秒 / 千字（8 线程）** |
| 可逆还原一致性 | 100% 严格一致 | 100% 严格一致（含 Word / Excel / PPT / PDF） |
